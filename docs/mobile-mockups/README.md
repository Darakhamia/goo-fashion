# Макеты мобильной версии

Этап 3 плана `docs/MOBILE_PLAN.md`. Смотреть макеты лучше на холсте, там есть масштаб и переключатель темы:

**v1 (2026-10-06):** https://claude.ai/artifact/TJiTGG5bV46G8R3CNeyTR8

## Что на холсте v1

7 экранов. В каждом ряду:
1. «Сейчас» — снимок стенда в тёмной теме: демо-каталог, вместо фото цветные заглушки.
2. Вариант А «Журнальный».
3. Вариант Б «Как приложение».

У каталога и страницы товара есть ещё светлые версии А и Б. На остальных экранах тема переключается тумблером `dark` во вкладке Tweaks.

| Ряд | Экран |
|---|---|
| 1 | Каталог, первый экран |
| 2 | Фильтры и сортировка (лист снизу) |
| 3 | Товар, первый экран |
| 4 | Товар, блок «Где купить» |
| 5 | Образ |
| 6 | Конструктор |
| 7 | Профиль |

v1 нужен, чтобы выбрать вариант. Остальные экраны выбранного варианта нарисует v2: главная, журнал, тарифы, лайки, корзина, стилист, вход, юридические страницы, 404. В v2 войдут и состояния «загрузка», «пусто», «ошибка». Прежние версии не затираются.

## Файлы

`v1/` — исходники артбордов холста (`*.dc.html`) и раскладка (`canvas.json`). Это запись дизайна, а не страницы для браузера. Они работают только внутри холста: картинки «Сейчас» лежат в его хранилище (`/_blob/…`).
