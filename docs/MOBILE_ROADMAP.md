## Как работаем

- Задачи берутся по порядку: статус Planned, все зависимости Done.
- Одна задача — один коммит. Один этап — один PR: CEO сливает его и после деплоя смотрит сайт на своём телефоне.
- Правки только ниже `md` (<768 px). Десктоп 1440 px после каждой задачи совпадает со снимком «до».
- Общая проверка каждой задачи:
  - снимки стенда «до» и «после»: 390×844 и 360×800, тёмная и светлая тема, плюс десктоп 1440 для сверки;
  - сверка с макетом Б на холсте;
  - чеклист `DESIGN_SYSTEM.md` §10;
  - `npm run lint`, `npx tsc --noEmit`, `npm run build` без ошибок.
- Вне роадмапа ничего не делается: новая находка сначала становится строкой здесь.
